ETS2/ATS Live Sync Converter 🚛

A web tool for Euro Truck Simulator 2 and American Truck Simulator players to decrypt/decode .sii files, search outputs, rename profiles, and convert weights/floats and text strings in real time.

Use it Live: https://trs120.github.io/ETS2-Live-Sync-Converter/

✨ Features

SII Decryptor: Decrypt and decode .sii files (ScsC, 3nK, BSII) in the browser and download the output.

Output Search: Search inside decrypted text with next/prev navigation, case toggle (Aa), and line filtering.

Weight & Float Sync: Live conversion between TON / KG / LB and SII Float32 hex.

Text & String Sync: Live conversion between plain text and hex strings.

🛠 How to Rename Profile

Open: https://trs120.github.io/ETS2-Live-Sync-Converter/

Convert: Type your new profile name in Text & String Sync and copy the Hex string.

Folder Rename: Go to Documents/Euro Truck Simulator 2/profiles (or American Truck Simulator/profiles) and rename the profile folder to the copied Hex string.

Update profile.sii: Decrypt profile.sii inside that folder using the SII Decryptor (or your decrypter), open it in a text editor, find profile_name:, and update it to your new plain text name.

Save & Launch: Save the file and open the game.
